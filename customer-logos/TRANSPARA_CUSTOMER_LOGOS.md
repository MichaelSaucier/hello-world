# Transpara Customer Logos — Print-Ready Sources
Source list: the 207 logos on [transpara.com/customers](https://www.transpara.com/customers/). For each, the best print-suitable file I could locate: vector (SVG/EPS/PDF) first, large raster second. Each row links the file page and, where it is a Wikimedia Commons file, a direct download. The Transpara PNG column is the existing 200–400px web asset, kept only as a fallback. Logos are trademarks of their owners; Commons licensing notes refer to copyright, not trademark.

**Grades:** A = vector, print-ready. B = large raster or vector from a non-official host, usable for most print. C = raster under ~1000px, check before print. F = nothing better than the web PNG found yet.
